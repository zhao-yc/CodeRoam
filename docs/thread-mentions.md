# 引用其他聊天

在已有聊天或新聊天输入框中输入独立的 `@`，可搜索当前执行电脑上的其他聊天。候选跨项目，按最近更新时间排序，排除已归档聊天、当前聊天和内部子任务；不自动打开候选聊天。

选中后在输入框上方显示可移除标签。每条消息最多引用 20 个不同聊天，正文、图片或文件附件仍至少需要一项。取消选择保留原正文，成功回执只清理本次提交的选择。未发送标签只保存在运行期草稿中，按电脑和聊天或新建项目隔离。

## 原生引用

手机只提交 `threadMentionIds`，电脑重新核对聊天编号及桌面实例，构造用户可见的引用链接及原生 `threadReferences`。模型上下文使用桌面原生引用序列化能力，要求当前智能体先调用 `read_thread` 再依赖引用内容。引用不复制整段历史，也不会主动给被引用聊天发送消息。

原生桌面或连接服务能力缺失时不展示入口；已有引用不可用时阻止整条消息，保留草稿，不静默移除引用。不会修改桌面安装文件、鉴权文件或原桌面数据库。

## 协议

- 新增只读 `threads.mentions`：接受 `search`、`offset`、`limit` 和可选 `excludeThreadId`，返回 `threads`、`hasMore`、`supportsThreadMentions`。候选只包含编号、标题、项目简称及更新时间，不返回路径和正文。
- `turn.send`、`turn.steer`、排队入队及 `thread.draft.send` 接受可选 `threadMentionIds`。客户端不能指定原生主机、引用路径或额外原生输入。
- 聊天及原生草稿快照通过 `supportsThreadMentions` 声明能力。
- 队列快照和撤回草稿通过 `threadMentions` 返回编号与标题，投递前重新读取最新标题和可用性。明确失败暂停队列，结果未知只核对原请求、不自动重发。

## 验收

自动化使用合成聊天与隔离索引，覆盖搜索、协议边界、普通发送、追加、首条消息、队列恢复及并发身份变化。HBuilderX Web 编译、浏览器交互、公网访问、真实桌面 `read_thread` 链路和 Android/iOS 真机结果分别记录，不能相互替代。
