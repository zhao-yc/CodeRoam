# 会话失败提示与重试

列表标题右侧的圆圈感叹号表示最新轮次执行失败。打开会话或标为已读不会清除失败标记；新一轮开始后改为显示运行状态。正常结束、手动停止以及单条工具执行失败不会因此变成会话失败。

详情在对应失败轮次末尾展示可复制的错误原文，只有最新失败轮次提供重试入口。没有消息的轮次也可显示错误。桌面未提供具体文本时显示“任务执行失败，未提供具体原因”。历史分页和本地缓存保留展示字段，缓存不恢复重试能力。

错误右侧“重试”和失败后空输入点击“发送”共用 `turn.retry({ threadId, expectedTurnId })`。服务端重新核对最新失败轮次、运行状态和待处理交互，然后通过桌面原有启动轮次接口以空输入继续上下文。不会重发上一条正文、伪造“继续”消息或创建空白用户消息。使用当前电脑端设置；用户可先调整模型再重试。

输入框有文字或附件时沿用正常发送行为。点击错误卡片的重试按钮不会消费已有草稿与附件。旧连接服务未声明 `supportsTurnRetry` 时显示更新提示。

请求处理中两个入口禁用，成功回执到新轮次到达前继续保留轮次占位。超时、断线、回执异常或结果未知时，客户端只保存电脑、会话及命令编号，不保存请求正文，并提供“核对重试结果”。恢复连接和刷新页面不自动重新提交；服务端沿用命令账本与会话锁。

协议新增可选的 `latestTurn: { turnId, status }` 与轮次 `errorMessage`。列表仅携带结果摘要，不广播错误原文。错误文本仅提取用户可见字符串或 `message`，不序列化内部错误对象、调用栈或请求参数。

单条错误最多保留 6000 字符，超过时明确提示截断；实时轮次元数据总量限制为 64 KiB，优先保留最新失败，较早记录随历史分页加载。避免错误堆积使会话超过传输上限。

桌面现有启动接口不支持按失败轮次进行原子条件启动。桥接会回读最新状态并拒绝已变化的任务；桌面同时在最后一次核对与原生启动之间操作，仍存在原生接口的并发窗口。不会通过修改桌面安装文件绕过这一边界。

验收分别记录单元与模拟测试、HBuilderX Web 编译、合成浏览器交互、公网版本核对、真实桌面及真机结果。浏览器验收使用合成会话；不以模拟成功代替真实模型容量错误的复现，不默认生成 APK。
