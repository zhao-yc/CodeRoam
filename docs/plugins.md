# 手机端插件选择

插件选择沿用原桌面的执行、审批与沙箱。手机只提交目录编号，不提交程序、目录、来源路径或原生输入。本链路不安装、不启用、不修改插件。

## 手机端交互

新建聊天和已有聊天均从加号菜单的“插件”打开底部面板，支持按名称或简介搜索、多选、确认和取消。单条消息最多选择20个插件；确认后显示可移除标签，取消不修改原草稿。失效选择单独标记，须取消后才能确认；旧连接服务或中转显示更新提示。

已有聊天按电脑和会话保存，新建草稿按电脑和项目保存，均仅保留在运行期内存。插件只用于本次消息，不能单独构成一条消息。发送或入队确认成功后清理对应选择；失败和结果未知时保留。提交后重新编辑过插件选择，旧回执不清除新的选择。关闭、切换电脑、项目或配对后丢弃迟到目录响应。

## 只读接口

- `thread.plugins.read({threadId})`：要求该手机已订阅且存在原桌面所有者与实时状态。查询结束后再次核对订阅 entry、所有者、工作目录及实例代次；退订或上下文改变则丢弃结果。
- `thread.create.plugins({projectId})`：项目编号由电脑项目列表解析成目录，异步查询结束后再次核对项目目录及实例身份。不能由手机指定任意目录。

成功结构统一为：

```json
{
  "supportsPluginSelection": true,
  "plugins": [
    { "id": "search@example", "name": "search", "displayName": "资料检索", "description": "检索合成资料" }
  ]
}
```

`PluginCatalog` 复用 `newThreads.creation.run(cwd, request => request('plugin/installed', {cwds:[cwd]}))`。实例模式将创建客户端固定到所选实例的 `CODEX_HOME` 和已核验桌面安装目录的随附 CLI；不能回退到另一安装或全局环境变量。原创建客户端错误码保持原样，插件边界单独转换为固定中文错误，不附带原始诊断。

目录只接受 `installed === true && enabled === true`，`availability` 为 `AVAILABLE` 或缺省，且没有 `disabledReason` 的记录。跨市场按 id 去重。显示名取 `interface.displayName`，缺省使用 `name`；简介取 `interface.shortDescription`。响应仅包含上述四个字段和能力标记，不带市场、来源路径、图标路径或市场加载错误。

## 发送与追加

`turn.send`、`turn.steer` 支持可选 `pluginIds`，最多20个，每个1至200字符，由英文字母、数字、点、下划线、`@` 和连字符构成，首字符必须为字母或数字。重复编号合并。队列只允许入队时提交此字段，取消及手动追加不能替换已保存的选择。

每次带插件发送都会重新查询最新目录；未安装、禁用、不可用或已撤销的选择直接拒绝。手机提供的 `input`、`restoreMessage`、`plugins`、`cwd` 和 `path` 等额外字段不在发送白名单内。

电脑生成原生输入 `{type:'mention', name, path:'plugin://'+id}`，其中 `name` 来自最新目录，并将 `[@显示名](plugin://id)` 追加到正文。标签中的 Markdown 特殊字符转义；原生输入保留目录原名。输入文本、`restoreMessage.text` 和 `restoreMessage.context.prompt` 使用同一份插件标记，文件附件继续沿用现有提示及恢复字段。只有插件不能构成消息；正文、图片或附件至少需要一项。未传 `pluginIds` 或传空数组时，不读取插件目录，也不增加目录短连接。

## 队列

入队保存原始正文、`pluginIds` 及目录中已核对的 `{id,displayName}`。快照仅增加可选 `plugins?: {id,displayName}[]`，不展示内部原生输入。自动发送和手动追加均通过适配器重新核对目录，使用投递时最新名称生成 mention。

插件失效或目录读取失败将队首标为失败并暂停后续消息，提示取消该项并重新选择插件；不会偷偷删除插件继续发送。桌面发送结果未知及崩溃中发送恢复后保持未知状态，不自动重发。旧 payload 不含插件字段时按原有格式正常恢复和发送。

## 验证边界

定向命令：`node --test tests/plugins*.test.mjs`。用例使用合成目录与桌面传输，覆盖过滤与字段投影、参数白名单、原生 mention 和恢复上下文、取消订阅与身份变化、队列再验证及旧 payload。模拟测试不能代替真实桌面插件执行或真机验收。
