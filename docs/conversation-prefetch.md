# 最近聊天持续同步

PC 守护进程为每个桌面实例维护最近聊天的展示副本。有已核验的桌面所有者时使用实时消息流，否则在索引或历史日志版本变化后重建最近窗口。守护进程自己的 SQLite 有界保存最近版本和上一版，重启后核对来源再复用。

手机前台连接时按授权电脑订阅最多 20 个近期会话，优先当前正在打开及活跃、未读会话。中转只路由订阅和转发事件。守护进程对已知版本只推送变化，无法续接时发送单个会话的最近窗口。后台、断线、换代和撤权都会使旧订阅失效。

点击聊天时直接显示本地副本，后台的详情订阅携带正文版本。完整窗口一致时，PC 只回当前实时状态和订阅游标。存在上一版基线时可以发送差异，其余情况回最近窗口。发送、停止、回答和审批始终由当前实时订阅授权。图片和更早历史继续按需读取。

旧中转或守护进程继续按列表 `contentRevision` 变化调用 `thread.history` 的 `prefetch` 只读视图。该路径沿用全局最多两路和单会话每秒最多一次的普通流式更新上限。

手机继续使用本地缓存的容量、授权清理和历史合并规则。已有副本即使滑出近期列表，仍可只核对会话是否存在。PC 明确确认归档或删除后才移除本地内容。只读同步既不切换原桌面页面，也不标记已读。

自动化使用合成会话覆盖内容版本、流式合并、并发、跨电脑隔离、缓存恢复与清理。Web 编译、浏览器、公网版本、真实桌面和手机真机验收分别记录。
