# 守护进程持续维护聊天

每个桌面实例由 PC 守护进程维护最近 20 个聊天的展示窗口。有已核验的 IPC 所有者时使用实时事件，否则核对索引与历史文件来源版本，变化时共享解析并更新 SQLite 中的最新与上一版本。归档或删除时清理。

手机通过当前聊天的 `thread.watch` 接收首屏和实时更新。守护进程已维护的正文先返回，桌面实时确认完成后接管，版本一致时省略重复正文。手机只保留当前页面内容，更早历史和图片按需读取。

手机跨聊天正文预取已移除。原 `threads.cache.watch` 和 `thread.history` 的 `prefetch` 只读视图保留给旧手机兼容。中转按设备授权和桌面实例转发，当前聊天的预览不能启用写操作。

具体行为及升级清理规则见[聊天数据与列表摘要](conversation-cache.md)。
