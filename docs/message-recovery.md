# 断线后查看会话并手动重发

手机连接恢复后沿用现有列表订阅和会话快照同步。用户查看最新会话内容，决定是否重新发送；程序不会自动重放创建、发送、追加、停止或审批等写请求。

- 设置页、会话页和新建面板移除“核对结果”及“核对旧版操作”入口。
- 请求正在等待响应时，仍按电脑和会话防止连续点击。超时、断线、发送失败、明确失败或未知结果回执都会释放提交状态，保留未确认的草稿，并提示查看会话后按需重试。
- 在途编号仅保存在内存。升级前的旧操作锁和新建回执不再恢复；清理旧存储失败也不会阻止读取和发送。
- 新建流程在当前面板内仍可复用已明确创建的空会话。重新打开面板会解除已结束流程的创建目标，保留未发送的输入；不会把新消息误送到旧会话。
- 用户主动再次发送使用新的请求编号。服务端原有请求去重、白名单、授权、审批和沙箱保持原有规则。
