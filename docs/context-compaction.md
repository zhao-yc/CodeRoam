# 上下文压缩状态

手机会话底部的运行状态支持自动和手动上下文压缩，显示“正在压缩上下文 · 可能需要几分钟”。顶部保留紧凑运行指示，不重复长提示。

电脑连接服务从当前运行轮次的 `contextCompaction` 项目读取状态：桌面实时快照的 `completed: false` 表示正在压缩，`completed: true` 表示完成；兼容显式的 `status: inProgress`，但缺少实时状态的历史项目不会被当作正在压缩。

压缩提示优先于压缩前的动作摘要。压缩完成后，只使用压缩之后的新动作；尚无新动作时显示通用“进行中”，避免重新显示过期摘要。任务结束、失败、等待用户操作或连接断开时，沿用对应状态，不残留压缩提示。

状态通过现有 `activity` 字段和增量同步通道发送，不插入聊天正文，不传输内部压缩内容，也不新增手机写操作或更改桌面的审批与沙箱。

验证覆盖压缩开始、完成、重复压缩、恢复执行、任务结束、增量同步以及手机状态优先级。合成测试和 Web 编译不代替真实桌面压缩事件及 Android/iOS 真机验收。
