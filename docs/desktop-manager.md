# CodeRoam · 电脑连接管理客户端

桌面管理客户端使用 Electron、Vue 3 和 TypeScript，第一版以 Windows 为运行和验收目标。它通过本机管理通道连接已经安装的电脑连接服务，提供运行概览、配置编辑、生命周期日志和受控重启。

管理客户端和 Node.js 24 守护进程独立运行。关闭窗口后客户端仍在托盘中，双击托盘图标或使用托盘菜单可重新打开窗口；选择托盘菜单中的“退出管理客户端”后，后台守护仍继续运行，手机连接不受管理窗口生命周期影响。

## 开发与构建

在仓库根目录使用 Node.js 24，先安装仓库依赖和桌面界面依赖：

```powershell
npm install
npm install --prefix apps/desktop-manager
```

常用命令均从仓库根目录执行：

```powershell
# 编译桌面管理界面。
npm run desktop:build

# 编译并启动 Electron 管理客户端。
npm run desktop:start

# 编译并生成 Windows x64 的本机运行目录。
npm run desktop:pack:win
```

Windows 打包命令要求在 Windows x64 环境下使用 Node.js 24。默认输出位于 `apps/desktop-manager/out/win-unpacked`，可从该目录运行客户端。界面使用本地打包资源，不依赖公网管理页面。

当前打包资源包含独立的 Node.js 24、桥接源码和所需依赖。首版管理已经安装的服务，尚未提供一键服务安装向导；打包目录不代表系统服务已经安装。Windows 安装、升级守护服务仍需按项目现有的托管流程操作，避免同时启动另一份桥接。

本说明不表示产物已经完成代码签名，也不表示已发布安装器。Mac 的本机通信接口保留，当前没有 Mac 真机验收结论。

## 关联现有服务

标准安装位置可自动发现时，客户端会尝试关联现有服务；也可以点击“选择服务配置”，通过本机文件选择器指定守护服务的 **`worker.json`**。

`worker.json` 是托管配置，其中包含桥接入口、业务配置文件、工作目录、运行记录目录和日志目录等固定路径。这里应选择托管配置，而非保存中转地址和配对信息的 `bridge.json`。管理客户端只记住所选托管文件的位置，不复制配对令牌。

现有守护需要升级到支持本机管理接口的版本。未选择服务时，界面会提示关联；已选择但接口暂时不可用时，界面会显示实际错误，不使用模拟在线状态。

## 查看运行状态

“运行概览”展示中转连接、可用桌面实例、后台进程以及已保存配置和当前生效配置的状态。状态约每 5 秒更新一次，也可以手动刷新。

运行状态的定时刷新不会覆盖配置页中尚未保存的输入。管理端只与现有守护通信，不因打开窗口、刷新页面或切换页面而创建另一份桥接。

## 后台数据同步

在「运行概览 → 后台服务」中可以切换「后台数据同步」。默认开启，守护确认后立即生效。开启时会自动更新聊天列表并预同步聊天详情。暂停后仍可手动打开聊天、发送消息和处理审批。

守护会保存开关状态并在重启后恢复。旧版守护会显示“当前服务版本暂不支持”，开关不可操作。

## 开机启动

在 Windows 管理端的「运行概览 → 后台服务」中可以切换「开机启动」。开启后，Windows 随系统启动托管服务，桥接在指定用户登录后连接中转。关闭后，Windows 将服务设为手动启动。

切换时按 Windows 提示确认管理员授权。管理端会读取系统服务确认后的启动类型。切换期间正在运行的服务继续工作。此设置由 Windows 保存，更新托管服务时沿用现有启动类型。选择手动启动后，下次开机可在 Windows「服务」中启动 `CodexMobileBridge`。

## 编辑与应用配置

首版开放以下配置：

- 电脑名称：用于手机端识别当前电脑，保存时需要填写有效名称。
- 中转地址：跨网络连接使用 `wss://`，地址中不能携带用户名、密码、查询参数或片段；本机调试地址可按后台校验规则使用 `ws://`。
- 多实例发现：控制是否自动发现本机的多个 Codex 桌面实例。
- 新聊天设置缓存：界面以小时设置有效期，并设置最多缓存的项目数量；默认值为 2 小时和 64 个项目。

配置通过本机管理接口校验和保存，保存请求携带读取时的配置版本。其他窗口或操作已经修改配置时，本次保存会被拒绝，应先重新读取并核对，再保存需要的调整。

**保存后的配置需要受控重启后台服务才能生效。** 保存成功后，可在概览确认“等待应用”状态，再使用“重启服务”。后台会先检查在途手机操作和任务；仍有操作处理时会拒绝重启，保持原服务运行。重启完成后，中转连接由守护自动恢复，界面显示实际生效状态。

尚未保存的输入不会随重启自动写入配置。相关配置文件变化会使对应缓存提前失效；服务重启后，内存缓存重新建立。

## 配对信息和日志

配对令牌保留在后台，界面只显示令牌是否已经配置，不显示令牌正文，也不提供通过本页面修改令牌的入口。

“运行日志”显示经过筛选的生命周期事件，例如服务启动、进程退出和自动恢复。日志按本机时区展示，可手动刷新；此页面不展示聊天正文、配对令牌或未经筛选的原始业务输出。

管理接口仅用于本机客户端。它不属于手机协议，也不需要对外开放额外管理端口。配置、配对信息及运行数据继续保存在项目约定的私有位置，不应随公开源码或桌面构建产物发布。
