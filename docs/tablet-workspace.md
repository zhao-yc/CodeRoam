# 平板分栏

可用窗口宽度达到 900 逻辑像素时，左侧以固定 340 像素显示聊天列表，右侧显示完整聊天。首次进入等待用户选择，不自动切换电脑上的聊天；窄屏使用单栏。两栏独立滚动，列表的搜索、排序和电脑筛选不改变右侧目标。

点击列表或通知由工作区打开聊天。切换前先卸载旧详情、保存缓存并取消旧订阅，再选择新电脑和聊天。目标身份包含配对、电脑及聊天编号，迟到回执不能影响新目标。窗口尺寸变化只重新排版，保留同一个详情组件、草稿和阅读位置。

“问问 Codex”入口保留在列表底部；新建编辑区显示在右侧，取消后恢复此前聊天，草稿继续按现有电脑和项目保存。归档或删除后，宽屏清空右侧并在列表更新后提示；窄屏返回原列表页再提示。独立详情路由及通知的待办定位继续有效。

聊天相关菜单和浮层限制在右栏，只渲染一份任务通知。连接设置继续使用独立页面。实现不修改后端协议、审批规则或未知提交结果保护。

验证分别记录 Node.js 测试、HBuilderX Web 编译、浏览器合成验收、公网版本、真实桌面及 Android/iOS 真机结果；Web 合成验收不能替代真机验收。
