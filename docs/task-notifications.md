# 全局任务通知

应用在首页、会话页和电脑连接页接收已授权在线电脑的会话状态。任务成功完成、异常失败、出现待回答问题、等待审批或计划待确认时，在标题栏下方显示浮动卡片。正在查看的聊天不再弹通知，其他聊天正常提醒；不同电脑的同号聊天独立判断。异步问题不要求任务先暂停。

进入聊天时，该聊天已显示或排队的通知立即移除；查看期间发生的事项也记为已读，离开后不补发。返回列表或打开其他页面后，后续新事项恢复正常提醒；断线恢复不会把仍在前台的聊天误当成未查看。

设置页的“通知时长”提供“5 秒”“10 秒”“不自动关闭”，默认 5 秒，选择保存在当前设备，重启或重新配对后仍保留。修改时长立即作用于当前通知，并从修改时刻重新计时；重复选择相同选项不会延长倒计时。

卡片进入动画约 200 毫秒，随后按所选时长停留并淡出；也可以单指向上划走，无需等待。不自动关闭时，当前通知会一直保留，划走或点击后才显示排队的下一条。上滑不会打开会话或自动处理待办。切换页面不重置倒计时；出现通知不会改变滚动位置、草稿或输入焦点。点击卡片才打开对应会话并定位结果、展开问题或定位审批和计划确认区，任何审批或发送仍需使用者主动操作。

首次进入、断线恢复或返回前台时，只补提醒仍待交互的事项，不补历史完成与失败。停止任务、离线和普通空闲不会被当成成功。重新配对、撤回授权或实例换代会清除旧通知；排队期间已处理的事项和已移除会话不再展示。

桥接在现有会话快照、增量和列表摘要中添加可选 `notificationState`：最新轮次编号、结构化结果状态、待交互事项的类型及身份。该摘要不包含问题答案、命令、消息正文或配对凭据。旧桥接缺少此字段时保留原有列表和会话功能，不推测生成通知。

## 浏览器系统通知

浏览器通知默认关闭。在电脑连接设置中点击“开启浏览器通知”才会申请权限，已有授权时直接开启。授权成功后可发送测试通知，拒绝后需在浏览器站点设置中重新允许。再次进入时读取已保存的设置，仅在通知已开启且浏览器权限仍有效时恢复通知服务。关闭此设置不会修改浏览器授予的权限。偏好只保存在当前浏览器，多标签页同步开关。

正在前台查看对应聊天时不弹页面卡片和系统通知；停留在其他页面或切换标签页、应用后，五类新任务事件通过系统通知提醒，包含事件类型和聊天标题，不包含正文、问题答案或审批命令。正在查看的聊天在前台仍被抑制，网页进入后台后该聊天的新事件可以提醒。系统通知不受页面卡片排队或时长影响，同源多标签页共用事件标签去重，不再因为应用窗口处于前台而拦截其他聊天的系统通知。

系统通知需要 HTTPS 或本机安全来源，以及浏览器的通知和 Service Worker 支持。本版优先支持电脑和 Android；iPhone/iPad 普通标签页显示支持限制说明，不包含主屏幕 Web App 专项适配。网页开启通知且服务就绪时，后台保留现有连接、列表订阅、心跳及重连；正文预取和后台删除任务继续暂停。关闭通知、撤回权限或通知服务失败后，后台连接恢复为原有的断开行为。

点击系统通知会优先唤起来源窗口，核对当前配对、电脑授权和实例后打开对应聊天并定位；断线时先恢复读取，不重放写请求。来源窗口已关闭或运行期映射失效时只打开首页，任何回答、审批、计划执行仍需使用者主动操作。更换配对或实例时清理旧通知及映射。通知映射只保存在运行期内存，Worker 只记录不透明票据和窗口编号，不保存令牌，不缓存页面，不订阅服务器推送。

网页需保持运行，关闭网页、锁屏或系统挂起后不保证送达；Service Worker 在本版仅负责显示和点击，不提供 Web Push。系统的免打扰、通知总开关也可能影响实际显示。

自动测试覆盖事件识别、时长、队列、去重、跨电脑隔离、重连、浏览器授权状态、后台连接和显式点击导航；Web 编译、合成浏览器验收、操作系统实际显示、真实桌面与 Android/iOS 真机验收分别记录。
