# 全局任务通知

应用在首页、会话页和电脑连接页接收已授权在线电脑的会话状态。任务成功完成、异常失败、出现待回答问题、等待审批或计划待确认时，在标题栏下方显示浮动卡片。当前会话也会提醒，异步问题不要求任务先暂停。

卡片进入动画约 200 毫秒，随后停留 5 秒并淡出。多条通知依次展示，切换页面不重置倒计时；出现通知不会改变滚动位置、草稿或输入焦点。点击卡片才打开对应会话并定位结果、展开问题或定位审批和计划确认区，任何审批或发送仍需使用者主动操作。

首次进入、断线恢复或返回前台时，只补提醒仍待交互的事项，不补历史完成与失败。停止任务、离线和普通空闲不会被当成成功。重新配对、撤回授权或实例换代会清除旧通知；排队期间已处理的事项和已移除会话不再展示。

桥接在现有会话快照、增量和列表摘要中添加可选 `notificationState`：最新轮次编号、结构化结果状态、待交互事项的类型及身份。该摘要不包含问题答案、命令、消息正文或配对凭据。旧桥接缺少此字段时保留原有列表和会话功能，不推测生成通知。

通知仅保存在运行期内存中，不增加系统推送。自动测试覆盖事件识别、时长、队列、去重、跨电脑隔离、重连和显式点击导航；Web 合成验收与真实桌面、Android/iOS 真机验收分别记录。
