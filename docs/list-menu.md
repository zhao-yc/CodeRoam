# 列表菜单

点击列表页左上角“掌上Codex”及下拉箭头展开菜单。点击空白处、再次点击入口或返回键可关闭。

- 默认按项目分组，项目内按更新时间倒序；项目组按最近活动先后排列。不同电脑、不同完整目录的同名项目分别保留。
- “优先级”依次显示待回答或待审批、执行中、未读及其他会话；离线电脑不显示过期运行状态。
- “按时间倒序排列”沿用今天、昨天、更早的分组。
- “优先显示‘最近’”将本设备最近查看的会话单独置前，最多保留 30 条标识，不重复展示，也不突破电脑和搜索筛选范围。
- 排列方式与最近开关保存在当前设备，首次使用默认选择“按项目”。

“已归档任务”只读查询已授权电脑的索引，支持分页，不激活、不恢复、不修改归档会话。旧连接服务缺少明确归档标记时提示更新服务，不能把普通会话显示为归档结果。

“添加连接”定位现有电脑连接页面的接入配置；“设置”进入同一页面的连接概览。

“剩余用量”按电脑分别展示真实账户额度窗口，剩余比例为 100 减已用比例。账户数据缺失、旧服务不支持或接口失败时显示“暂无法获取”，离线时显示“电脑离线”；这些显示不表示账户执行权限。查询只在菜单打开时发生，关闭、断线、取消授权或切换筛选后丢弃迟到回执。

归档与额度扩展复用白名单 `threads.list`，增加受限布尔参数 `archived`、`includeUsage`；连接服务升级后生效，旧中转不需要增加任意执行接口。

每台电脑的额度区同时显示其当前 Codex 登录邮箱；API Key 登录只显示登录方式，不显示密钥。账号通过受控短连接调用 `account/read`，不读取鉴权文件、不主动刷新登录，仅提取邮箱或登录方式。账号与额度分别失败时保留另一项；缺少账号信息时显示“账号暂不可获取”，离线或撤销连接后清空账号。账号仅供已授权手机查看，不写入运行日志、静态网页产物或公开仓库。长邮箱最多显示两行，窄屏菜单可滚动。
