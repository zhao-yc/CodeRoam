# 会话未读状态同步

手机列表的未读圆点来自桌面原生目录的 `isUnread`，由桥接转换为 `hasUnreadTurn`。任务执行中继续显示加载状态，空闲或状态未知且未读时显示绿色圆点。读取列表不应导航桌面或主动标记已读。

Windows 后台桥接不依赖聊天进程注入的管道环境变量。帮助程序先核对原生管道的安装路径和进程身份，再取得当前会话 IPC 的服务进程；原生工具管道必须与该进程一致。多实例、不同配置目录或启动顺序不能使桥接串到另一套桌面。

IPC 暂不可用时保留已验证的显式管道和单实例兼容；存在多个候选且无法唯一对应时返回不可用，保持未读状态未知。不会读取鉴权文件、修改桌面安装文件或写入桌面数据库。

回归覆盖无聊天环境变量的多实例选择、与环境变量冲突时的 IPC 优先级、对应实例缺失或重复、单实例兼容及非法管道。真实桌面同步、公网 Web 与真机验收分别记录。
