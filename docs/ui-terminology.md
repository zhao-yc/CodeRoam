# 界面名称

手机界面统一使用“聊天”，与 Codex 官方中文客户端的“新聊天”“搜索聊天”“归档聊天”“重命名聊天”一致。官方面向用户的英文文档也使用 [chat](https://developers.openai.com/blog/mastering-codex-remote-for-engineering)。

- 列表、搜索、新建、菜单、加载状态、通知、错误提示和无障碍标签均使用“聊天”。
- “任务”表示聊天中执行的工作，仍使用“任务”。
- 技术上的会话 IPC、会话 ID，以及原有的 `threadId`、`conversation` 等协议字段、代码标识和路由保持原有含义。
- 用户自己的标题、消息和桌面返回的原始错误不做名称替换。“对话框”仍表示弹窗。
