# 待回答问题的只读首屏

守护进程的最近正文展示窗口包含可选 `questionPreviews`：题干、标题、选项及保密输入标记。它随现有正文窗口写入守护进程自己的 SQLite，不新增手机正文落盘，也不修改官方桌面数据库。

展示副本使用独立的散列显示编号，不包含真实题组、轮次、请求目标、答案或审批权限。仅缓存待回答问题；题干、选项和问题移除都会改变展示版本。旧版数据库没有此字段时继续显示正文，后台取得新状态后补齐。单个问题展示集合最多 128 KiB，仍受现有 20 条最近正文及单窗口容量限制约束。

手机收到 `thread.preview` 后立即渲染锁定的问题卡片。只读预览中的 `questionGroups` 仍为空，旧中转和旧手机保留原有校验方式。实时快照接管后仅展示其中仍待回答的题组；已回答、失效或不存在的题组不会从旧副本恢复。

回答入口同时要求当前电脑和聊天的实时订阅确认、在线且非只读，并核对题组编号、轮次和待回答状态。缓存显示编号不能提交；守护进程继续以桌面的当前问题检查答案。断线、实例换代、撤权及快速切换沿用现有订阅代次隔离。

自动化分别验证 SQLite 重启读取、问题独立变版、答案及操作目标剔除、预览不能解锁提交、实时移除过期问题和断线关闭提交。HBuilderX Web 编译、公网资源、真实桌面只读读取及手机真机验收分别记录，不能相互替代。
