# 消息选项提交时机

全新聊天和已有聊天空闲时，模型、思考强度、速度、计划模式及权限选择只保存在手机草稿中。发送消息时通过一条任务携带这些选项，由连接服务只读校验后，将选项直接放入原生发送请求，与正文一次交给 PC，不额外创建设置任务。插件、引用聊天和附件仍属于该消息。

任务运行中，模型、思考强度、速度和权限继续实时提交到 PC；计划模式保留运行中禁用。实时提交表示电脑收到并确认选择，具体生效范围遵循原桌面能力，不承诺修改正在进行的推理或沙箱。任务开始或结束本身不触发设置写入。

普通发送与入队可携带可选的 choices，字段为 model、effort、serviceTier、mode、permissionMode、permissionRevision、confirmedFullAccess。权限选择必须携带选择时的版本，完整访问必须明确确认。supportsDirectMessageChoices 表示连接服务支持原生一次发送，supportsMessageChoices 保留旧协议兼容；旧服务不能自动降级为独立设置任务。

排队消息保存各自的选项快照，真正发送时直接携带；撤回编辑恢复原选项。原生追加接口只直接支持速度；草稿包含不同的模型、强度、权限或模式选择时须改为排队。电脑并发修改导致权限版本或设置不一致时拒绝发送并保留待核对内容。

含选项的消息在任务接纳时仍保留草稿及命令保护，明确发送成功或确认消息入队后才消费原提交版本。明确失败保留正文和选择，未知结果只核对原任务，不自动重发；后台核对得到终态后再收口保护。迟到回执不能清理提交后新增的文字或选择。

验证须分别记录模拟协议与组件测试、HBuilderX Web 与 Android 编译、公网资源访问、真实桌面及 Android/iOS 真机结果。
