# 会话输入区布局

空白输入区默认显示单行胶囊，同排提供加号、文字输入及发送或停止入口。点击或聚焦输入框后恢复完整编辑面板，显示权限、模型和附件工具栏。两种布局共用同一个 textarea，草稿、光标及焦点不会因布局切换而重建。

预测建议仍作为 placeholder 展示，出现后直接展开面板。使用同宽、同字体和同行高的隐藏文本测量自然换行及显式换行；文字区按每行 24px 显示，最少一行，最多六行。更长的建议限制预览高度，首次回车采纳后可在输入区内滚动。普通编辑保留 64–144px 的高度范围。

点击或聚焦不会采纳和发送预测；首次回车只填入草稿，再次回车才发送。Shift 换行和中文输入法选词沿用现有行为。

失焦或收起键盘后，只有没有草稿、预测、附件、打开的菜单及附件处理时才收起。失焦延迟处理，避免先隐藏工具栏而导致按钮点击失效；重新聚焦会取消待执行的收起。预测变化、会话切换和窗口宽度变化会重新测量，旧测量或页面卸载后的回调不能写回。输入区尺寸变化时更新菜单位置，并尊重用户当前的消息阅读位置。
