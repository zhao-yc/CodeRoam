# 会话输入区布局

空白输入区默认显示单行胶囊，同排提供加号、文字输入及发送或停止入口。点击或聚焦输入框后恢复完整编辑面板，显示权限、模型和附件工具栏。两种布局共用同一个 textarea，草稿、光标及焦点不会因布局切换而重建。

展开、收起及文字区增行使用 200ms ease-out 高度过渡，边框圆角同步变化。加号与发送／停止入口共用常驻节点，始终固定在底部两侧；两种状态统一使用单行时的左右和底部留白。加号图形为 22px、点击区域为 44px，发送圆形按钮为 40px、内部图形为 22px，切换时不位移或缩放。权限、模型及辅助停止入口在展开后的中间区域显示，连接提示位于编辑区上方。

过渡结束后补测菜单与消息位置；快速反向切换取消旧完成回调，会话切换和页面卸载也会使旧回调失效。用户阅读历史时继续保留阅读位置。

列表页底部入口与新对话编辑区也共用常驻输入和加号节点，展开、收起及增行沿用 200ms ease-out 过渡。收起时保留原有 50px 胶囊和加号坐标，展开时编辑内容向上增加，发送按钮在右下角显示。连接与发送提示放在面板上方，避免挤动底部图标。收起状态不读取新建项目或模型；每次重新打开仍解除旧创建目标并保留各电脑、项目的草稿，迟到聚焦和布局回调在关闭、重开及卸载时失效。

预测建议仍作为 placeholder 展示，出现后直接展开面板。使用同宽、同字体和同行高的隐藏文本测量自然换行及显式换行；文字区按每行 24px 显示，最少一行，最多六行。更长的建议限制预览高度，首次回车采纳后可在输入区内滚动。普通编辑保留 64–144px 的高度范围。

Windows 桌面预测优先从已绑定的官方桌面主进程只读获取现有缓存，普通启动和多实例共用该路径。身份由进程编号、创建时间、官方应用包路径及会话所有者共同约束。读取沿主宿主的预测服务、查询客户端和当前查询索引逐层定位，完整匹配主机、聊天及已完成轮次，两次回读均一致后才返回原文。

已完成轮次中的异步待答题允许与桌面已有预测并存。原生阻塞题、审批、运行中轮次和非空草稿仍隐藏预测，异步问题的回答入口独立保留。

辅助进程只申请操作系统查询与读取权限，使用父子私有标准流通信。缓存定位有字节、时间和候选数量上限；不保存内存转储，不记录原文，不执行目标进程代码或预测生成方法。既有页面读取通道继续兼容旧桌面布局。读取不设桌面版本白名单，遇到不兼容结构、实例变化、缓存清空或歧义时返回空预测。

读取同时支持旧的已选中标签面板和新版无标签主内容区。新版保留在 DOM 中但使用内联样式隐藏的后台工作区不得提供预测；两种布局均核对编辑器控制器、主机、会话及完成轮次，重复匹配仍返回空结果。

点击或聚焦不会采纳和发送预测；首次回车只填入草稿，再次回车才发送。Shift 换行和中文输入法选词沿用现有行为。

失焦或收起键盘后，只有没有草稿、预测、附件、打开的菜单及附件处理时才收起。失焦延迟处理，避免先隐藏工具栏而导致按钮点击失效；重新聚焦会取消待执行的收起。预测变化、会话切换和窗口宽度变化会重新测量，旧测量或页面卸载后的回调不能写回。输入区尺寸变化时更新菜单位置，并尊重用户当前的消息阅读位置。

## 验证

### 共用输入面板

新聊天与已有聊天统一使用 `message-composer` 组件，文字输入、附件与引用标签、加号、计划模式、模型入口和主按钮只维护一份。权限控件由具名插槽接入，电脑／项目选择、草稿保存、上传和聊天协议继续由业务组件负责。

Web 普通回车通知业务层提交，Shift+Enter 换行；其他修饰键、中文输入法选词和长按不触发提交。原生平台沿用确认事件，Web 不重复处理确认事件。新聊天复用原创建流程，已有聊天仍先采纳预测；空输入回车不会调用停止或重试。

测量节点与图片粘贴范围使用不含业务信息的实例标识，隐藏面板不接管粘贴。展开和收起保留同一个 textarea，窗口变化、目标切换、隐藏及卸载使旧布局回调失效。`tests/message-composer.test.mjs` 执行真实组件事件和两种业务提交方法，检查重复提交、失败保留、仅附件发送与布局隔离。

- `tests/mobile-composer-layout.test.mjs` 验证状态切换、延迟收起、测高上限、旧回调失效及窗口变化。
- 预测采纳、草稿隔离及原生节点结构继续运行现有回归测试。
- 平滑切换回归覆盖完成后补测、快速反向切换、会话切换及卸载取消；合成 Web 在 320px、390px、844px 宽度下逐帧检查，两端按钮坐标与尺寸偏差均为 0px。
- Web 编译、合成浏览器检查、公网访问及 Android/iOS 真机检查分别记录，不能相互替代。
