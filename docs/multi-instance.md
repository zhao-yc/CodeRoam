# Windows 与 Mac 多实例设备

已配对电脑上，当前用户运行的 Codex 实例自动显示为独立设备，不需要为每个实例重新生成手机令牌。Windows 和 Mac 均默认启用；手机原有的切换、名称和图标编辑继续生效；电脑授权被撤销时，其全部实例同时失去授权。

默认实例复用原电脑编号和操作账本。其他实例使用随机设备编号、独立的账本和附件目录。关闭实例后设备保留为离线；以相同配置目录和桌面用户目录启动时复用原身份。不同配置目录分别读取历史，共用配置目录则展示同一份已保存历史，不复制或修改 Codex 数据。

## 连接条件

### Mac

Mac 使用每套 `CODEX_HOME` 自己的 `ipc/ipc.sock`。连接服务只读核对当前用户、官方桌面签名、实际可执行路径、启动时间、私有工具套接字及 IPC 目录归属；环境读取仅提取 `CODEX_HOME` 和 `CODEX_ELECTRON_USER_DATA_PATH`，不读取登录文件。实例发现依赖本机 `/usr/bin/python3`；缺少 Python 或进程信息不可读时保持未就绪。

每个实例必须使用独立的配置目录；两个 Mac 进程共用同一 `CODEX_HOME` 时，相关设备均暂停操作。桌面用户目录可独立设置。仍可复用既有的 Mac 多开启动方式，桥接不启动或重启桌面，也不要求额外开启调试端口。

导航使用 macOS AppleEvent，将固定聊天链接投递给已核验的 PID，不由系统全局链接选择实例；手机只能提交聊天编号，不能提交程序、路径或脚本。最终加载成功由所选 IPC 的原桌面所有者及实时快照确认。每次手机请求、所有者发现、定向调用与导航都重新核对进程及独占目录；进程换代、目录被共用或发现失败时暂停原操作。只接纳该通道核验过的客户端回应和事件。

Mac 的原生未读同步、归档、永久删除、目标管理及输入预测仍按既有平台能力处理；多实例接入不代表这些功能已经适配。

### Windows

连接服务核对原桌面安装位置、当前用户、进程启动时间、原生管道及回环端口。支持的桌面页面通过固定的协调状态查询完成随机编号握手，绑定对应 IPC 客户端。后台执行器有独立连接，因此还会只读核对全部实例管理器的会话归属，仅用唯一持有的会话定位后台身份，并在绑定前再次核对所有实例；这个全局查询结果不能直接用于发送或订阅。后续会话发现、发送与广播均限定到已核验的客户端集合。原生工具和会话流必须同时绑定所选实例；无法核验时显示连接未就绪，不使用其他桌面代替。当前协调接口适配的桌面资源版本为 26.1027.3384.0；版本变化后不能把可见窗口当作已完成兼容验证。

已有实例不会被自动重启或更改调试配置。未开启可核验回环端口的实例，先在电脑保存并关闭，再运行项目的 `scripts/start-instance.ps1 -Config <本机桥接配置> -InstanceId <设备编号>`。启动入口从私有登记读取原目录，仅为新进程启用回环监听，不向外网开放端口，不改变桌面安装、登录或沙箱。正在运行的实例会拒绝重复启动。

如果同一会话已经由另一实例控制，手机会明确提示切换设备，不自动接管会话。发送、停止、审批等始终交给已核验的原桌面所有者。

## 协议和恢复

一条电脑鉴权连接承载多个实例。中转的 `hostInstances` 能力与 `host.instances` 完整清单用于登记所属设备；请求、回应及事件携带当前运行代次。实例换代后拒绝迟到事件；写请求结果不明时只核对原账本，不能自动重放。

本地 `instances.json` 保存私有目录到随机编号的映射，中转保存父电脑和设备编号的关系，名称与图标仍由原连接外观存储管理。`instanceBackupDirectory` 可指定私有实例登记备份目录；备份应连同原配对配置妥善保存，不能提交到公开仓库。连接服务的 `multiInstance: false` 可回退旧的单实例模式，默认实例账本不需要迁移。

升级顺序为中转、电脑连接服务、手机 Web。旧桥接继续按单设备连接；新版连接服务遇到不支持实例能力的中转会明确提示升级。Windows 与 Mac 复用同一套中转、设备列表及运行代次协议；Mac 的 `multiInstance: false` 也可回退原单实例连接流程。

## 验证边界

自动化测试使用合成设备和会话，覆盖隔离、生命周期、授权和操作去重。真实桌面的发现、目录归属、页面握手、列表及导航分别验证；模拟写操作、Web 编译、公网访问及 Android/iOS 真机结果分别记录。
