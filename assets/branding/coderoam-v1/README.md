# CodeRoam 正式标志

本版于 2026-11-05 确认采用靛蓝底、白色 C 形代码括号和前进箭头。各尺寸均由 `coderoam-logo-master.png` 导出。

| 文件 | 用途 |
| --- | --- |
| `coderoam-logo-master.png` | 1254 × 1254 原图，作为后续导出的基准 |
| `coderoam-logo-1024.png` | 高分辨率通用图标 |
| `coderoam-appstore-1024.png` | 无透明通道的 iOS 图标准备资源 |
| 其他尺寸 PNG | 用于对应尺寸的桌面、Web 和移动图标 |

Web 页签与触屏图标使用手机工程中的 32 和 180 像素文件，Android 离线模板使用各密度的 `ic_launcher.png`。Windows 打包图标在 `apps/desktop-manager/electron/icon.ico`。
