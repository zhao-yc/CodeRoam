# 手机端图标

来源：[@tabler/icons 3.49.0](https://github.com/tabler/tabler-icons)，MIT 许可证见 LICENSE。由官方 SVG 按深色、灰色、白色导出 72×72 PNG，以兼容 uni-app x 原生 image；没有运行时网络依赖。

本次输入区补充的 `camera`、`photo`、`plan` 为项目自行绘制的线性图标，按相同尺寸和三种颜色导出 PNG。

松墨界面补充：`file`、`chevron-right` 同样来自此版本官方图标，使用墨色、石灰色和白色导出。

连接编辑补充：`code`、`desktop`、`clock` 来自同一版本 Tabler 官方图标，按项目既有三种颜色导出。

权限选择补充：`hand-stop`、`shield-check`、`lock`、`alert-triangle` 来自同一版本 Tabler 官方线性图标，沿用 72×72 PNG 与三种基础颜色；警告图标另提供琥珀色 `warning`，工具栏、选中项及关闭入口统一复用 `app-icon`。

会话菜单补充：`target` 来自同版本 Tabler 官方图标，用于新建／查看目标；取消入口复用已有 `close`。

列表下拉菜单补充：`bell`、`archive`、`link`、`recent` 为项目自行绘制的线性图标，沿用 72×72 PNG 与三种基础颜色。

执行记录入口补充：`history` 为项目自行绘制的回转箭头与时钟组合图标，沿用 72×72 PNG、1.8 线宽和三种基础颜色，用于任务胶囊及展开后的历史入口。

加号菜单补充：`plugin` 为项目自行绘制的拼图线性图标，沿用 72×72 PNG 与三种基础颜色；追求目标复用已有 `target`。

提交任务状态沿用上述图形，保留透明度并补充语义颜色：`check-success` 为绿色（#16803d），`alert-circle-danger` 为红色（#d92d20），`clock-info` 为蓝色（#286bc1），`hand-stop-paused` 为橙色（#b35a16），`chevron-right-skipped` 为紫色（#8055b3）。待核对复用琥珀色 `alert-triangle-warning`，取消复用灰色 `close-muted`，执行中使用靛蓝色（#4546bd）加载动画，原生端与 Web 使用相同资源。
